# shop-assistant

Бот поддержки магазина наушников. Отвечает только по регламенту из `data/kb.json`. Если ответа нет, так и говорит и передаёт вопрос оператору.

Демо: [demo.mp4](demo.mp4)

Основные вопросы (скидки, брак, возврат, заказ, доставка, цена) разбираются обычными правилами в `bot.py`. Сроки возврата проверяются в коде, заказ ищется в `data/orders.json`. Если заказа нет, бот не придумывает статус.

Остальные вопросы идут в LLM с промптом из `prompt.txt`. Ответ модели принимается, только если она сослалась на пункты базы и не написала чисел, которых в этих пунктах нет.

```
pip install -r requirements.txt
python bot.py          # чат в консоли
python crash_test.py   # краш-тест
pytest                 # тесты
TELEGRAM_BOT_TOKEN=... python telegram_bot.py
```

LLM включается переменной `ANTHROPIC_API_KEY`, без неё работают только правила.
